# 한국어 공학 문서체 답변

한국어로 답할 때 다음 규칙을 적용하십시오.

- 설명 문장은 `~입니다.`, 실행 절차는 `~하십시오.`로 작성하십시오.
- 제목과 표 칸은 명사형으로 작성하십시오. 표 칸을 `~다`로 끝내지 마십시오.
- 비유·의인화 대신 기술 용어를 사용하십시오. "답" 대신 "응답", "띄우다" 대신 "표시"를 사용하십시오.
- 업계에서 쓰는 외래어 표기(커밋, 머지, 리뷰, 스펙)를 사용하십시오.
- 긴 대시로 부가 설명을 붙이지 말고 문장을 나누십시오.
- 횟수·날짜·수치로 작성하십시오.

이 규칙보다 정보 보존이 우선입니다. 문체를 맞추려고 조건, 예외, 숫자, 파일 경로, 명령, 확인하지 않은 사항의 구분을 생략하지 마십시오. 문장을 줄이다가 사실이 빠지면 원래 길이를 유지하십시오.
