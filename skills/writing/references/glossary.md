# 용어 대응표

`kolint.py`의 `metaphor` 규칙이 검출하는 표현과 권장 용어입니다. 문맥상 원래 뜻(실제 그림, 물리 시뮬레이션 등)이면 바꾸지 않습니다.

## 비유·일상어 → 기술 용어

| 피할 표현 | 권장 용어 | 예 |
|---|---|---|
| 답 | 응답 | 서버가 응답하지 않으면 |
| 묻다, 물어보다 | 요청, 조회 | 권한 상태를 조회한다 |
| 들고 있다, 붙잡다, 쥐고 있다 | 보관, 유지, 점유, 보유 | 잠금을 보유한 상태에서 |
| 띄우다, 뜨다, 그리다, 보여 주다 | 표시, 기동, 렌더링 | 권한 창을 표시한다 |
| 부르다 | 호출 | 서비스가 API를 호출한다 |
| 넘어지다, 죽다, 터지다, 깨지다 | 장애, 종료, 오류 발생, 실패 | 서버 장애 시 |
| 살아 있다 | 유효, 활성, 실행 중 | 토큰이 만료 전까지 유효하다 |
| 삼키다 | 무시, 누락 | 예외를 무시하지 않는다 |
| 흘리다 | 노출, 누락 | 신원이 노출되면 |
| 태우다, 돌리다 | 처리, 실행 | 배치를 실행한다 |
| 뱉다, 돌려주다 | 반환, 출력 | 400을 반환한다 |
| 짚다 | 측정, 선택, 지정 | 위치를 지정한다 |
| 꺼내다 | 조회, 추출 | 목록에서 추출한다 |
| 튕기다 | 거절, 실패, 제약 위반 | 유니크 제약 위반으로 실패한다 |
| 박다, 못 박다 | 하드코딩, 고정, 검증 | 값을 하드코딩하지 않는다 |
| 굳다 | 확정, 고정 | 시각이 확정된다 |
| 잡다, 잡아내다 | 발견, 검출, 획득 | 이 테스트로 오류를 검출한다 |
| 막다, 막히다 | 방지, 차단, 거절 | 중복 실행을 방지한다 (메시지 전송은 "전송되지 않음") |
| 적다 | 입력, 기록 | 결과를 기록한다 |
| 알아채다 | 감지, 발견 | 변경을 감지한다 |
| 믿다 | 신뢰, 가정 | 서버 값을 기준으로 한다 |
| 읽히다 | 인식 | 깜빡임으로 인식된다 |
| 튀다 | 급증, 순간 이동 | 비용이 급증한다 |
| 통째로 | 전체 | 목록 전체를 교체한다 |
| 갈 곳, 갈림 | 이동 대상, 분기 | 이동할 화면이 없다 |
| 시험 | 테스트 | 단위 테스트 |
| 늘 | 항상 | 항상 null이다 |
| 길목 | 경로, 지점 | 저장 시점에 변환한다 |
| 문턱 | 기준, 임계값 | 정지 기준을 초과한다 |
| 흐른다 | 처리, 전달 | 이벤트가 전달된다 |
| 그림자, 그늘, 뿌리, 손끝 (비유) | 삭제 후 사실로 서술 | 원인은 설정 누락이다 |
| 서버가 넘어졌다 | 서버 오류 | |
| 시간이 해결한다 | 일시적 장애로 재시도 시 복구 가능 | |
| 흐름을 태운다 | 흐름으로 처리 | |

## 순우리말 동작 동사 → 한자어 기술 동사

`native-verb` 규칙이 검출하는 동사입니다. 활용형("둔다"·"늘린다"·"줄였다"·"넘으면" 등)을 검출하며 "두 개", "한 줄이", "넘어지다"는 제외합니다.

| 피할 표현 | 권장 용어 | 예 |
|---|---|---|
| 두다 | 설정, 배치, 유지 | 최소 높이를 설정한다 |
| 늘리다, 늘어나다 | 확대, 증가 | 상자 높이를 확대한다 |
| 줄이다, 줄어들다 | 축소, 감소 | 라벨 글자를 축소한다 |
| 넘다, 넘치다 | 초과 | 줄높이가 상자 높이를 초과한다 |

## 번역어·전문어 → 읽기 쉬운 표현

`plain-term` 규칙이 검출하는 표현입니다. 원래 뜻의 "차단"(사용자 차단, 요청 차단)은 검출하지 않습니다.

| 피할 표현 | 권장 표현 | 예 |
|---|---|---|
| 크래시 | 강제 종료, 비정상 종료 | 채팅 목록 화면이 강제 종료됐다 |
| 존재를 단언하다 (`!`, assert) | 필수 조건을 걸다 | `!`로 `peer`에 필수 조건을 걸었다 |
| 단언 위치 | 조건을 건 위치 | 필수 조건을 건 위치에서 오류가 발생했다 |
| 전송이 차단되다 | 전송되지 않다, 전송 실패 | 메시지가 전송되지 않았다 |

도메인 용어는 검사기가 검출하지 않습니다. 서비스 화면에 표시되는 이름을 사용하십시오. 예를 들어 채팅 기능은 "대화" 대신 "채팅", "대화 목록" 대신 "채팅 목록"으로 작성합니다.

## 통용 외래어

순우리말로 풀어 쓰지 않고 업계에서 쓰는 표기를 사용합니다.

| 풀어쓴 표현 | 통용 표기 |
|---|---|
| 끝 조건 | 완료 조건 |
| 장치 | 자동화(훅·스크립트) |
| 왕복 | 수정 반복, 요청 횟수 |
| 되돌릴 수 없는 | 비가역 |
| 되돌리기 | 롤백 |
| 끌어 옮기기 | 드래그 |
| 병합 요청 | PR |
| 합치기 | 머지 |
| 검토 | 리뷰 |
| 차이 | 디프 |
| 명세 | 스펙 |
| 갈고리 | 훅 |
| 긴급 수정 | 핫픽스 |
| 범위 | 스코프 |
| 깔때기 | 퍼널 |
| 계기판 | 대시보드 |

## 제목·표 칸 명사형 어미

| 문장형 | 명사형 |
|---|---|
| 재시도한다 / 재시도하지 않는다 | 재시도 / 재시도 안 함 |
| 아직 응답이 없다 | 응답 대기 중, 아직 응답을 받지 못함 |
| 지원하지 않는다 | 미지원 |
| 사용하지 않는다 | 미사용 |
| 배포되지 않는다 | 미배포 |
| 확인해야 한다 | 확인 필요 |
| 가능하다 / 불가능하다 | 가능 / 불가 |
