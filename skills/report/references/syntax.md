# 보고서 Markdown 문법

`report.py`가 처리하는 Markdown 문법입니다. 일반 Markdown(문단, 목록, 표, 코드 블록, 링크)에 아래 확장 문법을 추가했습니다.

## 앞부분

```yaml
---
title: 서비스 운영 전망
subtitle: 2026년 3분기
org: 플랫폼운영팀
code: 문서 번호 PLT-2026-03
toc: true
layout: report
---
```

| 키 | 위치 | 기본값 |
|---|---|---|
| `title` | 표지 제목, PDF 제목 | `보고서` |
| `subtitle` | 표지 제목 아래 발행 시기 | 없음 |
| `org` | 표지 오른쪽 아래 작성 조직 | 없음 |
| `code` | 표지 오른쪽 위 문서 번호 | 없음 |
| `toc` | `false`이면 차례 생략 | `true` |
| `layout` | `compact`이면 단원 간지 쪽과 장별 쪽 나눔 생략. 단원 제목은 본문 안에 표시 | `report` |

## 제목

| 문법 | 용도 | 번호 | 차례 |
|---|---|---|---|
| `# 제목 {.front}` | 핵심 전제, 요약 등 본문 앞 구간 | 없음 | 표시 |
| `# 제목 {.appendix}` | 부록 | 없음 | 점선 아래 표시 |
| `# 제목` | 단원. 회색 간지 생성 | `Ⅰ.` | 표시 |
| `## 제목` | 장. 새 쪽에서 시작(`layout: compact`이면 이어서 배치) | `1.` | 표시 |
| `### 제목` | 소제목 | 없음 | 장 안에서만 표시 |
| `#### 제목` | 문단 제목 | 없음 | 미표시 |

`{.front}` 구간 안의 `##`은 장이 아니라 소제목으로 처리합니다.

## 문단

| 시작 문자 | 처리 |
|---|---|
| `**` (장 안) | 번호 문단. `1-1.` 번호와 파란 굵은 핵심 문장 |
| `⇒` | 굵은 결론 문단 |
| `※`, `주:`, `자료:` | 작은 글씨 주석 |
| `-` 목록 | 1단계 `□`, 2단계 `▪`, 3단계 `-` |

번호 문단 번호는 장마다 1부터 다시 시작합니다. `::: summary`, `::: box` 안의 문단에는 번호를 붙이지 않습니다.

## 인라인

| 문법 | 출력 |
|---|---|
| `**굵게**` | 굵은 글씨 |
| `{{6월 전망 대비 +0.1%p}}` | 작은 글씨 부가 설명 |
| `2026^e^` | 위첨자 |
| `본문[^db]` + `[^db]: 각주 내용` | 장 끝 각주 `1)` |
| `` `코드` `` | 코드 글꼴 |

## 블록

블록은 `::: 종류 인자`로 시작하고 `:::`로 끝납니다.

| 블록 | 인자 | 내용 |
|---|---|---|
| `::: summary` | 없음 | 요약 상자. 목록 1단계는 남색 굵은 핵심 문장 |
| `::: box 제목` | 제목 | `Box 1` 상자. 차례에 표시 |
| `::: note 제목` | 제목 | `참고 1` 상자. 차례에 표시 |
| `::: table 제목` | 제목 | `[표 1.1]` 번호 표. 끝의 `주:`, `자료:` 줄은 표 아래 주석 |
| `::: figure 캡션 \| 헤드라인` | 캡션, 헤드라인 | `[그림 1.1]` 번호 그림 |

`::: figure` 본문에는 다음 3가지 중 1개를 작성합니다.

- `chart: charts/latency.json` 보고서 파일 기준 상대 경로의 차트 JSON
- ```` ```json ```` 코드 블록에 작성한 차트 JSON
- `image: images/topology.png` PNG, SVG 이미지

연속한 `::: figure` 블록 2개는 가로로 나란히 배치합니다. 1개만 있으면 가운데에 60% 폭으로 배치합니다.

## 차트 JSON

```json
{
  "type": "line",
  "unit": "ms",
  "x": ["1월", "2월", "3월", "4월"],
  "series": [
    {"name": "p95", "values": [320, 310, null, 280]},
    {"name": "목표", "values": [300, 300, 300, 300], "dashed": true},
    {"name": "요청 수", "type": "bar", "values": [12, 14, 15, 16], "color": "#8eaadb"}
  ],
  "yMin": 0,
  "shade": {"from": "4월", "label": "전망"}
}
```

| 키 | 필수 | 값 |
|---|---|---|
| `x` | 필수 | 가로축 항목 목록 |
| `series[].values` | 필수 | `x`와 같은 개수의 숫자. `null`은 선을 끊음 |
| `series[].name` | 선택 | 범례 이름. 없으면 범례 미표시 |
| `type` | 선택 | `line`(기본값), `bar`. 계열별로 다르게 지정 가능 |
| `stacked` | 선택 | `true`이면 막대를 누적 |
| `unit` | 선택 | 세로축 위 단위 표시 |
| `yMin`, `yMax` | 선택 | 세로축 범위. 기본값은 값 범위를 포함하는 눈금 |
| `shade` | 선택 | `from` 항목부터 끝까지 연한 파란 음영과 `label` 표시 |
| `series[].dashed`, `series[].color` | 선택 | 점선, 색상 지정 |

기본 색상 순서는 남색, 빨강, 연한 파랑, 초록, 주황, 회색입니다. 값 개수가 `x`와 다르면 생성을 중단하고 오류를 출력합니다.

## HTML 표

머리행이 2단 이상인 표는 `::: table` 안에 HTML로 작성합니다. 전망 열 강조는 `class="hl"`, 하위 항목 들여쓰기는 `class="sub"`를 사용합니다.

```html
::: table 성장률 전망
<table>
<thead><tr><th rowspan="2">(%)</th><th colspan="2">2026</th></tr><tr><th>상반</th><th class="hl">하반<sup>e</sup></th></tr></thead>
<tbody><tr><td>GDP</td><td class="num">3.8</td><td class="num hl">3.0</td></tr></tbody>
</table>
:::
```
